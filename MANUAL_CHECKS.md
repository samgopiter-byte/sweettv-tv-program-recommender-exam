# Manual checks (done by the student)

Why: the report section "What I personally checked" must show numbers that a reader can recompute from a table (teacher's words:
put a table and a calculation example taken from it). Every check below is meant to be done **by hand first** (calculator or the
PowerShell commands below), compared with the expected value afterwards, and then reported in the chat with the student's own
numbers. Only what the student reports is entered as *confirmed* in `VERIFICATION_LEDGER.md`.

## Part 1. Commands to run in Windows PowerShell

**S1. Row counts of the raw files** (one line per file, takes about a minute). Expected: 5821987, 1074235, 1074394, 1295378.

```powershell
$raw = "C:\Users\pc01\kaggle-midterm\data\raw"
foreach ($f in "dataset11-30.csv","export_arh_11-20-final.csv","export_arh_21-30-final.csv","export_arh_31-42-final.csv") {
  $n = 0; Get-Content "$raw\$f" -ReadCount 200000 | ForEach-Object { $n += $_.Count }
  "{0}: {1} data rows" -f $f, ($n - 1)
}
```

**S2. The file that was submitted is the file in the repository.** Expected hash `0E5DE6ECAB6CF6433EE7E6516A4C3440`.

```powershell
Get-FileHash -Algorithm MD5 C:\Users\pc01\kaggle-midterm\submissions\submission_v6_ensemble.csv
```

**S3. Format of the submission and one programme looked up in the test schedule.** Expected: 1260, 5, 5, and one or more schedule
rows dated 27.07.2020 or later (the Russian titles may look garbled in the console; look at the dates).

```powershell
$s = Import-Csv C:\Users\pc01\kaggle-midterm\submissions\submission_v6_ensemble.csv
$s.Count
$s[0]
($s[0].tv_show_id -split ' ').Count
($s[0].tv_show_id -split ' ' | Select-Object -Unique).Count
$id = ($s[0].tv_show_id -split ' ')[0]
Select-String -Path C:\Users\pc01\kaggle-midterm\data\raw\export_arh_31-42-final.csv -Pattern ",$id," | Select-Object -First 3 | ForEach-Object { $_.Line.Substring(0, [Math]::Min(110, $_.Line.Length)) }
```

**S8. Rebuild everything from the raw files and compare** (about 10 minutes, needs about 4 GB of free memory; close other programs).
Expected last line: `IDENTICAL: the rebuilt file equals the submitted file byte for byte`.

```powershell
powershell -ExecutionPolicy Bypass -File C:\Users\pc01\kaggle-midterm\reproduce.ps1
```

**S9. Kaggle Submissions page** (https://www.kaggle.com/competitions/sweettv-tv-program-recommender/submissions): compare each row
(file name, Public score, Private score) with the table in `submissions/SUBMISSIONS.md` and check that the Russian name in the
description is displayed correctly.

## Part 2. Hand calculations from the generated sheet

`MANUAL_CHECKS_data.md` (generated by `src/manual_checks.py`) contains four checks with blanks for the student's own arithmetic:

* **S4** screen time of one airing from raw view rows (overlap of two views with the airing, divided by its length, compared with 0.8);
* **S5** the truth of one user: count the committed airings per programme, take the five most frequent, find the tie at the 5th place;
* **S6** expected number of committed airings of one programme from the slot habit: rate = hits / (airings + 1) per airing, summed;
* **S7** AP@5 by hand for two users of the final model, one whose truth has no randomness and one where a tie decides one place.

For each check the sheet shows the raw data first and the code's answer after a separator; compute your value before looking at it.

## What to send back

For each check: the number you got (and, for S4-S7, the intermediate values of your calculation). The agent compares them with the
code's answers, records the outcome in the ledger, and the report quotes them as "calculated by the student" with the table they
came from.
